# 事件写法

推荐的事件摘要只回答三件事：发生了什么、为何需要注意、下一步需要谁做什么。

- `NeedsConfirmation`：`需要选择部署环境；选项会改变生产影响范围。`
- `Blocked`：`等待用户提供未包含的访问凭据；未尝试读取或发送秘密。`
- `GoalCompleted`：`已完成导入并通过目标测试；没有对外发送任何数据。`
- `ExecutionFailed`：`本地构建在依赖不可用后仍无法继续；已保留失败类别而非日志。`
- `PermissionRequired`：`即将请求允许下载开发依赖；仅影响当前工作目录。`

不要把命令行、测试日志、报错堆栈或密钥复制进 `summary`。
